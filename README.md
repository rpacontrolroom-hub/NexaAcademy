# NEXA Academy - Plataforma educacional

## Tecnologias

- React
- TypeScript
- Vite
- Bun
- Tailwind CSS

## Como rodar

Tenha salvo no CRTL + V o seguinte bloco de comando: 

```bash
bun install
bun run dev
```

Acesse o endereço exibido no terminal, normalmente a porta será:

```text
http://localhost:5173
```

## Scripts

```bash
bun run build      # build de produção
bun run preview    # visualizar o build
bun run lint       # validar lint
bun run typecheck  # validar TypeScript
bun test           # rodar testes
```

Ou

Peça para o codex rodar!
